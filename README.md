# PhilGEPS Schema Analysis

Reference repository for **PhilGEPS open-data schema evolution (2000–2025)** and **mapping to a canonical field model and [OCDS](https://standard.open-contracting.org/) 1.1.5**.

Use this repo to answer: *What column names appear in which export era? How do they normalize to one schema? How does that relate to OCDS and PhilGEPS 1.5/2.0 internal fields?*

**This repo does not include raw CSV/XLSX data or an ETL pipeline** — only documentation, mapping config, and JSON/markdown references. Raw exports live on [Google Drive](https://drive.google.com/drive/folders/1kkqBC60VPHmdlZfntu3A-8pSKAdIh2Nx?usp=sharing).

---

## Quick start

```bash
git clone <repo-url>
cd philgeps-schema-analysis
```

**No install required** to read the references. To regenerate derived files:

```bash
pip install -r requirements.txt
python scripts/build_schema_field_map.py
```

→ [docs/GETTING_STARTED.md](docs/GETTING_STARTED.md)

## Run the webapp

The `app/` directory is a Vite + React + TypeScript single-page app that renders the schema mappings interactively (canonical field browser, OCDS crosswalk, OCDS staged output, codelists, schema evolution, global search). It reads a single bundled JSON generated by the build script — no backend.

```bash
# 1. (Re)generate the data bundle from YAML + JSON references
python scripts/build_schema_field_map.py

# 2. Install and run the dev server
cd app
npm install
npm run dev      # http://localhost:5173
```

Production build: `npm run build` → static files in `app/dist/`.

→ [app/README.md](app/README.md) for full details
